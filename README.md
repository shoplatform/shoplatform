# 開店平台 · 骨架版 v0.3

零抽成、年費制的電商開店 SaaS 平台，這是第一階段的「鋼骨結構」。
（獨立專案，與金融工具無關。）

目前完全不需要伺服器：打開 `index.html` 就能跑，資料先存在瀏覽器裡。

## v0.3 新增

- **前台會員註冊／登入**（藍圖 A2-01）：帳號是手機號碼。註冊要先拿手機驗證碼——簡訊還沒串接，所以目前是「示範模式」，驗證碼直接顯示在畫面上。密碼至少 8 碼、要有英文和數字，只存加鹽雜湊（SHA-256），不存原文；密碼連錯 5 次暫停 5 分鐘。以前用同一支手機結帳過的顧客，註冊後會自動接上原本的訂單。
- **會員中心**：我的訂單、修改姓名與 Email、變更密碼、登出。登入後結帳會自動帶入會員資料，訂單直接掛在會員帳號下。
- **訂單查詢**（藍圖 A2-02）：不用登入，輸入訂單編號＋下單手機就能看訂單進度（待付款 → 備貨中 → 已出貨 → 已完成）、物流單號、付款說明。顧客看不到商家備註；手機號碼會遮一部分。
- **顧客自行取消**：「待付款」的訂單顧客可以自己取消，庫存自動加回；已經在處理的訂單要聯絡客服。
- **下單完成頁**：可以直接「查看訂單」；還不是會員的話，提示「設定密碼成為會員」，按下去會帶入剛剛的手機和姓名。
- **後台會員頁**：顯示每位會員「已開通／未開通」帳號。
- **示範帳號**：手機 `0912345678`、密碼 `demo1234`（林雨潔）。

> 這一版也修掉一個問題：以前沒登入結帳時，會用 Email 去比對既有會員，打錯或借用別人的 Email 會讓訂單掛到別人名下。現在只用手機比對，而且不會覆蓋已開通會員自己維護的資料。

## v0.2 新增

- **商品圖片上傳**（藍圖 B1）：商品編輯頁可以點選或拖曳上傳，每個商品最多 8 張；第一張是主圖，可以「設主圖」、「移除」。圖片會在瀏覽器裡自動縮小（長邊 1200px）並轉成 JPEG，透明背景會變成白底。前台列表、商品頁（可切換多張圖）、購物車、後台列表都會顯示主圖；沒有圖片的商品照舊用色塊。
- **訂單匯出 Excel**（藍圖 B2-06）：訂單頁右上角「匯出 Excel」。依照目前的狀態分頁和搜尋條件匯出，可以再選「不限日期／本月／自訂日期」。下載的是真正的 `.xlsx`，有兩張工作表：「訂單」（一張訂單一列）與「訂單明細」（一個商品一列），標題列凍結、可篩選，金額有千分位，手機號碼開頭的 0 會保留。不需要任何外部套件。

> **圖片目前的限制**：圖片跟其他資料一起存在瀏覽器的 localStorage，大約只有 5MB，一般商品照片大概能放 20～30 張。空間不夠時會跳出提示、不會存到一半。等換成真正的後端（階段 2），圖片會改存雲端，這個限制就沒了——只需要改 `js/db.js` 裡的 `DB.media.prepare()`。

## 現在能做什麼

**商家後台**（`#admin`）
- 總覽：今日／本月營收、待出貨、會員數、近 14 天營收圖、低庫存提醒、最新訂單
- 商品：新增、編輯、刪除、上架／草稿、多規格（例如 顏色 × 尺寸 自動組合）、每個規格各自價格與庫存、**商品圖片**
- 分類：新增、改名、刪除
- 訂單：依狀態分頁、搜尋、訂單詳情、手動確認收款 → 出貨（填物流單號）→ 完成、取消（庫存自動加回）、**匯出 Excel**
- 會員：結帳時自動建立、累積消費、訂單紀錄
- 設定：商店資料、免運門檻、低庫存提醒、取貨方式與運費、付款方式開關、重置範例資料

**商店前台**（`#shop`）
- 會員註冊／登入、會員中心、訂單查詢（v0.3）
- 首頁、分類、搜尋、商品頁（選規格、看庫存、數量、**多張圖片**）
- 購物車（免運差額提示）
- 結帳（訂購人、超商取貨或宅配、付款方式、備註）→ 下單完成頁
- 下單會自動扣庫存、建立會員、出現在後台

**刻意還沒做的**（照藍圖排在後面）
- 金流、物流、電子發票串接 → 目前付款與出貨都由商家在後台手動確認
- 簡訊驗證碼真的發送（目前示範模式）、忘記密碼
- 優惠券、導購分潤、多商家註冊、年費計費

## 怎麼在自己電腦上打開

直接用瀏覽器打開 `index.html` 就可以。
上方黑色的 **DEV** 列可以在「商家後台」和「商店前台」之間切換。

資料存在瀏覽器的 localStorage：換瀏覽器或清除網站資料就會回到範例資料。
後台「設定 → 重置範例資料」也可以手動還原。舊版留下的資料會自動升級，不用重置。

## 放上 GitHub（GitHub Pages 免費網址）

1. 在 GitHub 建一個新的 repository，例如 `shop-platform`（Public 或 Private 都可以；Pages 免費版需要 Public）
2. 把這個資料夾的檔案上傳：
   - 最簡單：在 repository 頁面按 **Add file → Upload files**，把整個資料夾內容拖進去，按 **Commit changes**
   - 或用指令（這個資料夾已經是 git 專案）：
     ```bash
     git remote add origin https://github.com/<你的帳號>/shop-platform.git
     git branch -M main
     git push -u origin main
     ```
3. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等 1～2 分鐘，網址會是 `https://<你的帳號>.github.io/shop-platform/`

已經放過舊版的話：用 **Upload files** 把新檔案拖進去覆蓋即可（新增了 `js/xlsx.js`，別漏掉）。

## 檔案結構

```
shop-platform/
├── index.html        入口，載入所有 CSS / JS
├── css/
│   ├── base.css      共用色彩、按鈕、表單、表格（含深色模式）
│   ├── admin.css     商家後台版面
│   └── shop.css      商店前台版面（之後的「佈景主題」從這裡長出來）
└── js/
    ├── seed.js       範例資料（虛構店家「晨霧選物」）
    ├── db.js         資料層 ← 之後換成真正的後端，只改這個檔案
    ├── ui.js         共用工具：金額格式、提示訊息、確認視窗、網址路由、下載
    ├── xlsx.js       產生 Excel 檔（不靠外部套件）
    ├── admin.js      商家後台所有頁面
    ├── shop.js       商店前台所有頁面
    └── app.js        啟動：依網址顯示後台或前台
```

## 設計原則

- **頁面只跟 `DB` 說話**：所有讀寫都經過 `window.DB`（包含圖片的 `DB.media`）。之後接上資料庫與 API，只要把 `db.js` 裡的函式改成呼叫 API，頁面不用重寫。
- **多租戶從第一天就在**：資料結構是 `stores[商店ID]`，現在只有一家示範店，之後開放多商家時不用改資料形狀。
- **不用任何框架或打包工具**：純 HTML / CSS / JavaScript，任何人打開就看得懂，也方便用 AI 一段一段加功能。
