# v0.60 測試與交付範圍

本版為 POS＋光貿電子發票第一階段測試版，尚未部署至正式 Supabase、GitHub 或啟用商家正式金鑰。

已完成的驗證：

- 光貿官方公開測試帳號：憑證查詢成功、實際開立合成測試發票成功、用原訂單識別碼查回相同發票號碼與金額。
- 開票核心 11 項測試通過：B2C、公司統編拆稅、捐贈／載具互斥、金額核對、簽章、加解密、首次開票、逾時查詢、作廢／金額異常轉人工核對等。
- POS 資料庫回歸 13 項通過：現場銷售、共用庫存、自訂組合、交班、通路及權限。
- 新增發票資料庫測試 22 項通過：店家隔離、密鑰不可讀、防重複結帳與扣庫存、單一發票工作、處理鎖、逾時原識別碼、手動模式、現場寄送與運費開票。
- 完整 SQL 重複執行通過；v0.59 增量升級重複執行通過，商品與原設定售價保留。
- JavaScript／TypeScript 語法檢查通過。
- 瀏覽器操作驗證：光貿設定、離線 POS 收款、找零、庫存更新、發票列表、SKU Enter、公司統編欄位、正式資料層本機登入與 POS 載入。
- 390px／1280px 介面檢查無水平溢出，桌面結帳按鈕保留在收銀區底部。

尚未完成的驗證／功能：

- 正式 Supabase Edge Function 部署、排程與商家正式帳號驗收。
- 全套歷史測試沒有全部通過：目前包含舊定價／試用天數預期、進階方案測試前置資料、備份版本預期，以及分類重複與商品上限相關項目。以上未在本次逐項修復，因此不得把本次 POS／發票測試通過解讀為全平台正式上線驗收完成。
- 尚未自動串接發票作廢／折讓、退款金流、補寄通知及發票機。退款或取消會標記「需人工核對」，由商家至光貿處理。
- 外部開票結果不明時，系統只查原交易，不自動建立第二張；商家需在光貿核對後處理。

測試用 PostgreSQL 使用暫存本機資料目錄，沒有連線修改正式資料庫。測試依賴不包含在 GitHub 上傳包。
